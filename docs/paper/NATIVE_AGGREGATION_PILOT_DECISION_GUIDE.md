# Prospective decision guide for the original-MMReD pilot

This is an unfrozen decision memo, written without inspecting pilot predictions. It releases no experiment and changes none of the frozen [evaluation rules](NATIVE_AGGREGATION_MMRED_OFFICIAL_EVALUATION_PROTOCOL.md). Numerical validity, ordinary-model competence and scientific usefulness are separate decisions. Publish every arm and uncertainty interval. A failed qualification heuristic is not proof of a zero effect; an inconclusive result remains inconclusive.

The current experiment can show a complete-answer difference under its fixed training recipe, including measured transfer to longer test sequences. It cannot alone establish a general aggregation improvement, content-specific attention-mass benefit or reasoning composition. The official test is historically used, the pilot has one fit seed, and ordinary versus memory differs in parameters and computation. The ordinary input retains all native visual tokens; the compressed inputs retain a fixed summary. Any gain can involve learnability as well as representation. The [objective-alignment note](NATIVE_AGGREGATION_OBJECTIVE_ALIGNMENT.md) explains why one batched forward is not itself evidence of less work or better aggregation.

**If mass wins the registered comparison.** A qualified mass-over-ordinary and mass-over-normalized result supports usefulness of the mass-bearing representation under this recipe. It does not show that mass counts objects or preserves arbitrary bindings. The next experiment should be one prospectively powered, new-world replication of the original task law and unchanged training recipe with two independent fit seeds, not a search for a favorable seed. Balance answer priors and predeclare answer-changing counterfactual families alongside the original task endpoint. Independently requested evaluation questions may test preservation of other facts, but must not silently become extra training supervision. Fix sampling, exclusions, sample size, decoding budgets and endpoints before fitting. This tests whether the pilot gain survives new worlds and initialization. Greater relevant-load and multi-question training studies are a subsequent, separately controlled step; they cannot be mislabeled as an exact replication of this one-question-per-world pilot. Failure to replicate ends the mass-benefit claim for this configuration.

**If normalized memory wins but mass adds no reliable benefit.** The supported result concerns a compressed representation/readout under the tested budget. Do not attribute it to multiplicity or retune the mass channel. The next experiment should first replicate the aggregation gain on fresh worlds with two fixed fit seeds, preserving the original task law, training recipe and ordinary comparison. If it replicates, test whether normalized memory improves complete aggregation answers over an appropriately adapted ordinary baseline within a genuine native reasoning setting. This is the path toward the user's aggregation/composition objective. Failure to replicate ends this configuration's aggregation-gain claim; failure of the reasoning comparison leaves a plain-model result rather than a demonstrated composition benefit. Equal accuracy at lower cost alone remains efficiency. Independent-question prefix reuse is an optional later efficiency/generalization study, not a prerequisite for either aggregation gain or reasoning-token composition. Additional factual and relation questions can still test coverage using separate cold prefixes; a failure of optional reuse narrows the reuse claim without erasing an independently established cold aggregation result.

**If both memories fail with a competent ordinary baseline.** Stop this fixed-summary configuration; do not follow with a slot-count, loss, normalization or schedule sweep. One final diagnostic is defensible only if its answer would change the research direction: use the frozen final checkpoints on a predeclared counterfactual sensitivity panel that varies relevant evidence separately from distractors, including matched-total-length comparisons. Keep task programs, visual identities, answer priors and the rendered Step range in support. Include atomic questions and answer-changing relation pairs, without fitting another model. A memory deficit that grows specifically with relevant load localizes a useful failure boundary; a deficit already at elementary supported queries does not identify a load bottleneck. Neither pattern alone proves information loss: finite decoder approximation, optimization and the native language interface remain possible causes. If no useful regime emerges, retire this summary approach. Such a diagnostic is not permission to patch the architecture until the same benchmark passes.

**If ordinary competence fails.** Compact-model superiority would remain a comparative score under a weak reference, not persuasive evidence of a better aggregation mechanism. The next experiment should be ordinary-only competence diagnosis on newly fixed, answer-balanced visual counterfactual pairs using the unchanged native format and full image input. Pair supported atomic lookups with aggregation questions; hold the question constant while changing the relevant visual answer, and include an unchanged-answer control. Score the complete pair, format validity and truncation separately. This distinguishes an answer-prior shortcut or failure to respond to visual evidence from a narrower relational failure without replacing the benchmark parser. If valid complete answers still fail elementary counterfactual grounding, stop comparative memory claims until a competent ordinary reference exists. If formatting dominates, any later format/interface correction must be separately specified and applied fairly; it cannot retroactively repair pilot predictions. The diagnostic itself is not another fit or automatic training-budget extension.

The [relevant-load note](NATIVE_AGGREGATION_RELEVANT_LOAD_DESIGN_NOTE.md) supplies the central data-control distinction. Longer official MMReD worlds contain the same people and rooms; length changes integration and ordinal exposure. A subsequent study must vary independently answer-relevant relations or bindings, separately account for distractors, and include matched total lengths. Preserve training exposure to the rendered Step range and visual classes. Avoid calling extra repetitions, more answer tokens or added irrelevant images “greater relation capacity.” A multi-question training panel changes supervision exposure, so all methods must receive that same panel; the current one-question-per-world result cannot stand in for it.

Before a **content-mass claim**, require replicated mass-over-normalized gains on primary relation answers, preserved independent retrieval, and a separately fixed item-count-only channel control. The latter substitutes a question-independent log native-item-count signal for log attention mass while retaining the same channel shape and training protocol. Equal-count, equal-position counterfactual worlds are needed to test a content-dependent advantage. Normalized means already preserve relative frequencies, while log mass also carries item-count and score-scale information. A benefit only on numeric answer priors or changed formatting is insufficient. Exact replication identities apply to identical enriched items; changing their positional coordinates changes those items. The [core proposal](NATIVE_AGGREGATION_VISUAL_MEMORY_CORE_PROPOSAL.md) already records these limits.

Before a **reasoning-composition claim**, first establish the fixed method's plain-model benefit against a competent, appropriately adapted ordinary baseline. Then use a genuine native reasoning backbone with its real reasoning template and a prospectively bounded allowance, scoring complete final answers separately from thought length. Compare ordinary versus memory within that same reasoning setting, and direct versus reasoning modes on the same backbone/checkpoint where the native model supports them. A Qwen-versus-Cosmos difference alone does not isolate reasoning. No intermediate correct labels or forced thought continuation may enter the memory. Require memory to improve the reasoning baseline while checking factual and relational coverage; longer traces alone are not composition. Reasoning-token composition can use one cold visual prefix and the ordinary autoregressive cache throughout the thought and final answer. Reusing that visual-prefix cache across independent questions is not necessary. Any additional coverage questions may start from their own cold prefixes.

Only if a later study separately claims independent-question prefix reuse, establish a new, unchanged-threshold native cache-parity proof first. The current cold pilot does not qualify independent-question prefix reuse. In that optional study, both ordinary and memory controls must construct their question-independent prefix once, fork/reset question and answer KV equally, and retain one ordinary decoder forward per generated token without local decoder banks or extra VLM calls. For every aggregation comparison, measure the complete budget: vision, memory construction, prefix prefill/copy where applicable, every answer or reasoning token, latency and memory. The common budget must let the ordinary baseline consume all evidence and complete its answers; do not manufacture an advantage by starving that control. Useful aggregation accuracy at matched total measured inference budget is the target; cheaper noninferiority alone is efficiency. Original shared feature preparation must remain charged, and instrumented timings must not be presented as production latency.

The [existing primary-literature review](NATIVE_AGGREGATION_REUSABLE_MEMORY_HYPOTHESIS.md) documents the closest precedents: BLIP-2, Flamingo and Matryoshka Query Transformer for learned visual compression, HiLS for selective access to retained evidence, and prior numerator/normalizer and cardinality-aware attention work for mass-related algebra. These precedents constrain the claim. A small learned-query resampler or an extra normalizer channel is not a new attention principle. The possible contribution is a reproducible complete-answer improvement with a measured cost advantage or matched-budget accuracy gain, a controlled relevant-load boundary, and successful plain/reasoning composition. None of the four pilot outcomes alone establishes that contribution.
