# Decisions after native factor trainability

Written before examining fresh factor predictions. This note changes no registered threshold, dataset or resource release.

Both fixed factor models solve108/108 native training scenes. The simplest current description is a learned per-image feature map, vector summation, and a residual readout conditioned on the question and emitted prefix. Multiplication is an optional feature-map choice with an equally sized additive control; no product-specific advantage is established. These are parallel N+1-stream methods, whose computation is explicit.

The immediate decision is fresh composition. Complete triples preserve questions, person sequences, room/person marginals and backgrounds while changing the unique joining person. Solving full triples requires using information beyond those marginals. Panel A measures new realizations of fitted combinations, with training and opposite orientations separated. Panel B changes person groups. Panel C also changes room-pair questions and which images are irrelevant. C failure alone would not isolate language understanding.

If neither fixed endpoint passes both A and B, preserve the failure and stop before the registered N32/N64 evaluations. Do not tune on this fresh panel or reclassify it as training. A subsequent training-coverage study would need a separate prospective design and fresh confirmation. Strong A with weak B supports realization transfer but limits composition; strong A/B with weak C supports familiar-query composition only.

If either endpoint qualifies, evaluate both fixed checkpoints on every already frozen N32/N64 panel. These nested scenes retain relevant evidence and insert only irrelevant images. They also change positions and canonical Step labels, so a decline is not a pure diagnosis of SUM drift. Measure runtime and memory at those lengths before release.

The ordinary frozen joint-image reference shares inputs and backbone but has no fitted adapter. Any gain combines adaptation and routing differences. A later adaptation-matched ordinary joint control must pass its own training screen before a structural aggregation advantage can be inferred. Equal forward-call counts do not establish equal compute.

After useful fresh and length transfer, test several independently requested facts in the same context and the use of multiple aggregate directions. A rank-one projection can show reliance on discarded directions in a fitted representation; it cannot establish a minimum information dimension or rule out a differently trained scalar code. Single-join success is insufficient evidence for increased general aggregation bandwidth.

Finally, the current final-normalization write does not persist in native KV state. It can affect subsequent tokens through the emitted prefix. Useful reasoning composition needs a same-backbone direct/reasoning comparison with measured accuracy and total cost. Previously verified native KV mechanics demonstrate software capability, not a reasoning gain. The broader objective remains open.
