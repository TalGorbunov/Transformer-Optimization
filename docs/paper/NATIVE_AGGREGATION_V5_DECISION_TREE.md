# V5 decisions after the registered experiment

This is planning, not an additional registered experiment or authorization for automatic model searches. No V5 main efficacy outcomes existed when this note was written.

V5 compares SUM with MEAN over identical independently read visual messages. At fixed parameters and query, SUM is the visible-image count times MEAN. A win would support extensive scaling together with its optimization consequences. Shared learning rates and joint gradient clipping make training dynamics part of that treatment. The contrast cannot establish increased representational capacity, necessity of independent memory, or reasoning composition. Its relative five-point screen has no absolute usefulness floor, and the reused tests remain exploratory.

| Outcome | One next experiment | What it can establish |
|---|---|---|
| SUM wins in both seeds | Fresh dependent second-query assay with a controlled correct intermediate selection. Clone identical caches through that prefix, vary valid selections requiring different visual evidence, and intervene on the branch only when answering the second query. | A benefit lost when the later read is disabled supports conditional reuse after a changed reasoning state. Autonomous composition additionally requires generated intermediate selections under matched token budgets. A null late intervention does not exclude earlier propagated contributions. |
| Both arms improve similarly | One contemporaneous hidden-only adapter control against predetermined MEAN, matching placement, refresh schedule, seeds, upper LoRA, optimizer, selection and parameter count as closely as possible. Report compute separately. | Improvement beyond ordinary hidden-state adaptation is needed to attribute a gain to frame access. Historical V4 seeds cannot provide this causal control; V1's global adapter failed a similar attribution check in V2. |
| Both fail | Frozen-message local-readability audit before another architecture: fit a small diagnostic classifier on separate fitting contexts, then evaluate held-out full contexts with positives, character-only negatives and room-only negatives, including length transfer and fixed-marginal binding pairs. | Reliable conjunction separation would challenge a failure-to-extract explanation and redirect analysis toward pooling, optimization or native numeral readout. Poor linear separation is not evidence of information absence. Labels are diagnostic targets only, never branch inputs. |

Use the planned observational messages to quantify negative-message means/variance, accumulation with frame count, and branch-to-native-attention-output norms. Zero-read centering guarantees zero only for a zero read; it does not guarantee that irrelevant images contribute zero. The paired decomposition must include changed Step-label pixels as a confound: mapped original frames retain semantics but are generally rerendered after interleaving. Vector decomposition is descriptive, not a causal isolation of context.

The isolated/full-context Yes/No gap motivates testing evidence access. It does not show that V5's small raw-vision reader has the abilities of the entire isolated VLM, and the indexed full-context task also imposes reference resolution. None of the outcomes alone justifies replacing the reader with a reused pretrained FFN.

## Engineering interpretation

Retaining native quantized dispatch with an explicit pre-efficacy engineering exception is defensible when branch state and fixed-input computation are verified and native numerical discrepancies are reported. The strict numerical gate remains failed. Finish missing reset/software checks before release; audit every dev-selected checkpoint on fixed cases afterward, without selecting checkpoints or rerunning an arm based on these measurements. Efficacy concerns the ordinary cached implementation. Substantial cached/full answer disagreement after training would limit claims of equivalent per-forward behavior. A production kernel patch introduced solely to cross an arbitrary numerical threshold would add an unnecessary change.
