# What the identity join can establish

**Scientific scope note; no new experiment is released.** Complete the fixed [gate audit and vector-versus-count pilot](NATIVE_AGGREGATION_IDENTITY_JOIN_PROPOSAL.md) before expanding the comparison. A vector advantage can establish useful evidence content beyond a relevance count. It is not, by itself, evidence of increased aggregation bandwidth or a competitive new aggregation method.

The implemented scalar control receives an exact binary count and the text-only global state. Its local contents and gate positions cannot reach the residual; repeated dense work only matches projection cost. With six correctly included images, it receives the same information across all three answer-changing variants. Its deterministic answer can therefore be correct on at most one variant. This is a deliberately restricted negative control, not the strongest alternative method. [Implemented boundary](../../gnnformer/parallel_local_binary_aggregation.py).

The global question does **not** list the three people. If each exact observable cell—question, N and native input layout—is balanced over all nine answer names, the scalar ceiling is actually 1/9, not 1/3. Aggregate answer balance alone does not establish that stronger ceiling: audit conditional balance and identical captured global states/counts. The per-triple 1/3 bound remains valid without the stronger balance assumption. Invalid names can lower either result. A vector score merely above a very low scalar baseline is insufficient evidence that the join was learned.

The most informative existing endpoint is correctness on **all three variants of a complete fresh family**, separately for seen and held-out room pairs and both lengths. The people, their occurrence slots, background, person frequencies and room frequencies are held fixed; the person–room associations and correct answer change. Consistent success therefore requires sensitivity to something beyond those marginals. Preserve every triple, including gate failures or violations of the scalar-input identity. Do not report only favorable variants.

## Remaining shortcuts and limits

The interface provides a strong task decomposition: a frozen native binary decision first removes everything outside the requested rooms. This is legitimate measured inference, but it is neither a learned general relevance policy nor an answer-independent guarantee for arbitrary questions. The proposed audit must pass as specified. The room-pair holdout is withheld from branch fitting, while the fixed gate audit explicitly sees all fifteen pairs.

Nine known names, six known rooms and exactly six relevant images form a small finite world. A learned vector may encode a histogram of person–room types, a compact code or a task-specific sufficient statistic. Any of those can solve this join without using anything close to 96 independent coordinates. The pilot does not distinguish them, require 96 dimensions, measure transmitted bits, or prove that the native decoder implements a general joining algorithm. Conditional elementwise maps followed by SUM already have the Deep Sets form. [Deep Sets](https://arxiv.org/abs/1703.06114).

Randomized occurrence positions and counterbalanced room assignments reduce generator shortcuts but do not eliminate every finite-template strategy. Canonical Step labels, atom reuse, family construction and correlations between positions and roles remain potential cues. Complete-triple accuracy rules out predictors using only preserved marginals; it does not rule out a learned pattern recognizer using a few diagnostic associations. Report the declared holdouts precisely, without calling them unseen people, unseen visual primitives or unrestricted compositional reasoning.

N8/16→N32/64 increases distractors while the six relevant images remain fixed. That tests resistance to irrelevant context, not capacity as the number of independently required facts grows. N+1 native streams also consume real vision, decoder and KV resources. One batched forward is not equal compute to one ordinary joint-image stream. A low-rank residual before the final norm is not persistent aggregation memory: at a fixed token history it leaves the backbone KV unchanged. Name generation is not a reasoning-composition assay.

## One follow-up, conditional on a useful pilot

Add **one same-parameter joint-native adapter comparison**, not a sweep of pooling operators. Give the frozen backbone the ordinary joint-image prompt containing every image and the identical global question. At its final query, feed that joint hidden state as both the global input and one local input to the same rank-96 tanh/SUM/SiLU residual core, with gate one. This uses the same 1,041,600 trainable parameters, native cast/norm/head and unmasked name-plus-EOS output. It computes no external join or relevance count.

Compare this joint adapter with the parallel vector adapter on identical training families, fixed update budget, paired seeds and final-only checkpoints, followed by new common test families. Use **CE-only in both arms** for this follow-up. The current identical-global residual-consistency helper cannot be copied to joint-image length pairs: their frozen global states differ. A common CE objective avoids silently changing that contract. Freeze source, native replay checks, feature inventories and a measured resource reservation before any fit; no failed result licenses extra tuning.

Report whole answers and complete triples alongside allocated time, generated tokens, peak memory and actual native/vision calls. Matching trainable parameters and updates does not match inference FLOPs. If the vector adapter does not improve on ordinary joint adaptation, the negative-control result remains evidence of content use without a practical advantage. A reproducible advantage at an acceptable measured cost supports separately preserving evidence for native answer generation. Independent encoding and generative fusion already have close precedent in FiD; this would be an empirical result in this native adapter setting, not a new attention family. [FiD](https://aclanthology.org/2021.eacl-main.74/).

Even a positive follow-up should use the claim “useful aggregation of associations beyond a relevance count.” A bandwidth claim still requires a separately justified task whose independent evidence demand increases. That is outside the current gate and fit release.
