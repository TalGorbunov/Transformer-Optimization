# What evidence should follow V18?

**Draft proposal, not a registration or resource release.** Prepared without reading V18 efficacy outcomes. The following are three distinct claim tests, not a commitment to run a campaign. V18's fixed report and existing success criteria remain authoritative.

V18 compares a counting-specific native semantic filter with an all-open control. Both learn bounded vector payloads and a native answer readout, execute the same probe, and retain the same training and inference work. A positive result would show that preserving a reliable local counting judgment helps this aggregation problem. It would not establish a general relevance detector, increased information capacity, or beneficial reasoning composition. A negative result would leave useful local classification intact while rejecting this particular route from it to reliable aggregate answers. [V18 design](NATIVE_AGGREGATION_VISION_V18_DESIGN.md), [V17 local evidence](NATIVE_AGGREGATION_VISION_V17_RESULTS.md).

The research question is which evidence survives combination and remains useful at later queries. Conditional elementwise transformation and summation already have the Deep Sets form; independent evidence processing followed by generative fusion has a close precedent in FiD. These ingredients cannot carry an attention-operator novelty claim. [Deep Sets](https://arxiv.org/abs/1703.06114), [FiD](https://aclanthology.org/2021.eacl-main.74/).

1. **Distinguish native answer transfer from recognition of trained counts.** Keep the V18 gate, architecture, optimizer and inference unchanged. Compare gate versus all-open after restricting adaptation and descriptive development to even answers in 0–16; evaluate fresh paired N32/N64 scenes covering both even and odd answers. Use identical retained pair orders, seeds and a fixed update budget across arms. Remove odd complete answers from all supervised targets and selection; shared numeral tokens and prefixes can remain. Existing training contexts need not be advertised as fresh.

   Freeze an absolute usefulness threshold for odd whole-answer accuracy, alongside the matched gate advantage and seen-answer guard, before fitting. Complete native integer plus EOS is decisive; first digits are insufficient. Transfer by both arms supports the shared pipeline, without establishing an additional gate benefit. Failure on odd answers limits the claim to trained answer support. This is unseen *adaptation-answer* transfer within a counting task: the pretrained model already knows numerals. It does not establish K>16 extrapolation, new visual concepts, or general aggregation. An unrestricted-number claim would still require a separate test beyond the maximum training count.

2. **Require evidence content that a retained-item count cannot answer.** Use one non-count, multi-image identity join, for example “Which person appears in both room A and room B?” Construct unique-answer scenes where neither supporting image alone resolves the join. Counterfactual pairs should preserve N and the number of potentially relevant frames while changing the correct identity. Hold out complete contexts and entity/room combinations, and report constituent-evidence failures separately from native full-answer failures.

   The existing one-image count probe is ineligible here. Prospectively freeze one generic question-conditioned relevance prompt and its native probability rule, then validate its evidence coverage before fitting; never derive gates from the known answer or a task-specific external parser. Compare gated and all-open vector aggregation with identical probe work and training. Keep the final answer in the unmasked native vocabulary, without an external join or tally. Success would support a useful relevance/value interface beyond cardinality, but would be a newly validated interface, not zero-shot transfer of V18's literal 0/1 prompt. Failure to retain a necessary supporting image rejects that fixed filter for this task. Success only on counting is not evidence for general vector aggregation. Neither outcome establishes bandwidth: that claim additionally needs a measured compute-matched comparison as the number of independent required facts grows. N+1 streams are real work.

3. **Test benefit under reasoning and benefit from adding reasoning separately.** First finish the proposed Cosmos local-probe audit. A reasoning-prefill state is not automatically a valid digit measurement. The candidate uses direct instructions for original local probes and the official reasoning prompt for the global row. A subsequent streaming check must cover the fact that direct local rows receive shared reasoning continuations. New Cosmos weights, prompts, gates and prefix states require their own identities; Qwen caches are ineligible. [Prospective probe audit](NATIVE_AGGREGATION_REASONING_GATE_AUDIT.md).

   Then cross gate/all-open with direct/free-reasoning policies on the same Cosmos backbone, fresh paired scenes and matched seeds. Give both trained conditions identical direct-answer supervision and outcome-filtered natural trace CE, including thought positions; preserve all teacher attempts and freeze a coverage rule before collection. Correct final teacher answers do not certify every thought. Keep consistency on matched direct prefixes, not unmatched traces. Answer-only teacher-forced CE cannot train earlier final-norm branch outputs through later fixed-prefix states.

   Fusion must provide visual access in every cell. Disabling it during thoughts makes the text-only global row scene-blind and is an invalid reasoning control. Require a gate advantage within reasoning to claim persistence, and reasoning to improve over the same method's direct policy to claim beneficial policy-level composition. Report whole answers, truncations, tokens, latency and memory under prospectively measured budgets; equal token caps do not imply equal computation. A fixed original gate cannot reopen evidence for a newly chosen subquestion. Do not generalize this experiment to arbitrary changing-query reasoning.

Persistent memory is a distinct mechanism, not a prerequisite inferred from counting gains. V11 demonstrated an earlier-write gradient path, not efficacy. If reasoning benefits warrant that question, compare common-read pre-last and final-norm writes with historical writes live during training, then intervene on historical writes while preserving current evidence access. Moving a frozen V18 core earlier changes its representation contract and would not isolate memory. [Existing memory evidence and limits](NATIVE_AGGREGATION_AFTER_V14.md).
