# V14: learn in centered coordinates, then distill the mean

The question is whether a model can aggregate visual evidence reliably at each ordinary decoding step. V13 did not solve this: both centered models failed the practical MMReD length-extrapolation target. Its jointly trained correction also departed substantially from the empirical irrelevant-image mean it was intended to estimate. [Verified V13 results](NATIVE_AGGREGATION_VISION_V13_RESULTS.md).

V14 changes the training principle while retaining the native inference operator. During task training, form messages for the actual images and for 24 known-null training references at the same question and strict prefix. Subtract the exact occurrence-weighted reference mean from each actual message in the aggregate. Differentiate through this mean, including its dependence on the question and the message encoder. Once the core finishes its fixed training schedule, freeze it and fit the small continuous query-to-mean predictor to its fixed means. Only this predictor is used at inference.

For a given query, adding an arbitrary shared vector d to every actual and reference message leaves the centered statistic unchanged: the actual sum gains N*d and the subtracted mean contributes the same N*d. Full differentiation preserves this cancellation during learning. V13 instead gave the task loss permission to repurpose its mean predictor, while a finite regression penalty tried to keep that predictor calibrated. Separating the two phases removes that particular conflict.

The matched control uses exactly the same reference means, training examples, task losses, core and predictor sizes, optimizer schedules, and fixed phase lengths. It subtracts the mean once instead of N times. The two conditions run with seeds18 and19. Each trains the core for4590 updates, freezes it, then trains the predictor for8000 updates. A single final development evaluation is descriptive; every final model is evaluated on the same272 fresh contexts. [Registered protocol](../../PREREG_AGG.md), [execution artifacts](../../outputs/native_aggregation_vlm/v14/INDEX.md).

This design has two distinct failure points. The core might fail to learn transferable aggregation even with empirical centering. Or the small predictor might fail to reproduce the means that core used during training. Complete conversion diagnostics therefore accompany the accuracy experiment: all972 query/prefix groups and all4266 unique ordinary training positions, with projected mean errors and changes in the nonlinear residual. These diagnostics do not select checkpoints or substitute for complete native answers.

At inference the method retains N local image streams and one global text stream in one batched backbone call per generated token. It uses the original vocabulary head and ordinary greedy decoding, with no reference images, external tally, restricted answer vocabulary, or training-length anchor. A batched call with N+1 streams still costs more than a single stream; equal forward-pass count is not equal computation.

Empirical centering does not guarantee that unseen positions have the same irrelevant-message distribution, remove individual-message variance, or ensure that the compact predictor can represent every mean. The references are question-specific training supervision. Centering and invariant set aggregation have close antecedents; neither is a novelty claim here. The possible contribution is a demonstrated native aggregation improvement with a clear diagnosis and a compact training-to-inference conversion. Reasoning-token composition remains a separate, untested objective.
