# What would meet the aggregation objective

The objective is useful aggregation within one model forward per generated token, including a benefit when a reasoning model produces multiple tokens. That outcome remains open. The97% counting result is narrow; all216-context identity-join models tried so far fail their training screen. No current model supports a general bandwidth or reasoning benefit.

The completed moment-basis comparison tested explicit cross-image interactions at the same288-dimensional statistic width and parameter budget. Both arms failed, and the subsequent LP audit left complete linear separation unresolved. Its factorization-machine/set-pooling algebra is known prior art. This line is closed; neither an information-capacity claim nor another readout sweep follows from it. The selected ordinary joint-image LoRA control instead establishes a missing competence baseline. It changes adaptation scope, parameter count, exposure and compute, so it cannot identify why the earlier aggregation adapters failed.

The current architecture processes N+1 parallel native streams. One batched forward per output token does not imply the compute of one ordinary global stream. All vision prefills, decoder streams, token counts, latency and memory must remain visible in any comparison. Its final-normalization residual is outside KV; effects on future reasoning steps currently arise through generated prefixes. Software compatibility with a reasoning backbone has not established a useful reasoning benefit.

A prospective direction is a compact visual memory constructed before any question and read by one ordinary decoder across questions and generated reasoning tokens. The ordinary joint comparator must also reuse its image-prefix KV cache, and question/answer KV must reset between independent questions. The present cached features are question/prefix-dependent and cannot implement this contract. Learned visual compression and resampling already have close precedents, including BLIP-2 and Flamingo; the potential contribution would require a demonstrated accuracy/cost advantage as relevant evidence increases, with controlled multi-question reuse. This needs a new world-disjoint, multi-question dataset, a competent adapted ordinary baseline and native validation. No such benefit or memory implementation is released by the current LoRA profile.

A useful final result needs natural-answer and reasoning comparisons against both the frozen ordinary model and an appropriately adapted baseline. Any explanation must separate increased relevant load from longer distractor context, representation width from finite-budget learnability, and stream parallelism from reduced computation. These are experimental requirements for the original objective, not reasons to expand a failed architecture sweep.
