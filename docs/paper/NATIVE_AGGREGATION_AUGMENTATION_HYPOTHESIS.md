## Exact aggregation read

Let H=3584, R=128 and K=32. Let x_i be the frozen native postmerger image features. Use the normalized route of the existing [NativeVisualMemory](../../gnnformer/native_visual_memory.py) unchanged: its 24 fixed frame/raster sin/cos coordinates c_i, parameter-free FP32 RMS normalization with epsilon1e-6, learned key matrix A in R^(128×3608), and learned slot queries s_j in R^128 give

`k_i = A [RMS(x_i); c_i]`

`mu_j = SUM_i softmax_i(s_j^T k_i / sqrt(128)) x_i`.

Coordinates remain zero-based frame_index/128 and merged-raster centers, with frequencies1,2,4,8. Values are the original x_i. The core receives neither question nor answer/prefix. Set retain_mass=False; freeze its existing mass_direction at zero and exclude it from the optimizer. Do not initialize from a fitted replacement-arm checkpoint. The normalized summary is recomputed when its trainable parameters change.

For each eligible native hidden state h_t immediately before block27, define four bias-free FP32 matrices W_Q,W_K,W_V in R^(128×3584) and W_O in R^(3584×128):

`q_t = W_Q RMS(h_t);  a_j = W_K RMS(mu_j);  v_j = W_V mu_j`

`p_tj = softmax_j(q_t^T a_j / sqrt(128))`

`r_t = W_O SUM_j p_tj v_j`

`h'_t = h_t + cast_native(tanh(alpha) r_t)`.

Use one scalar alpha, initialized exactly zero. Every RMS above is `v.float() * rsqrt(mean(v.float()**2)+1e-6)`, independently over its H channels, with no learned gain. All summary/read arithmetic, including softmax, is FP32; perform the residual addition in the original native hidden dtype, without converting the native stream to FP32. The additional read has one head, no dropout, extra FFN, biases, learned normalization, mass channel, token insertion or RoPE. Its query can depend on the current question and previously emitted tokens through h_t; the summary itself cannot. The full original image evidence remains available to the ordinary native self-attention at every block.

## Live parameter match and initialization

The aggregation arm has seven trainable tensors: A and the32 slot queries, four read matrices, and alpha. Their count is

`128*(3584+24) + 32*128 + 4*3584*128 + 1 = 2,300,929`.

The 3,584-entry mass_direction in the reused core is frozen zero state, not a trainable or optimizer parameter. The pool therefore contributes465,920 active parameters. No learned adapter tensor is permanently inactive by construction, although the zero gate initially blocks gradients to the branch weights.

The pointwise control is the standard bias-free bottleneck residual

`r_t = B_up SiLU(B_down RMS(h_t))`

with B_down in R^(321×3584), B_up in R^(3584×321), and its own scalar zero-initialized tanh gate. It uses the same native residual addition, placement and eligibility mask. Its three trainable tensors have exactly `2*3584*321+1 = 2,300,929` entries. Width321 is fixed solely by exact parameter matching; there are no padding parameters or fake memory inputs. It sees the same native h_t, which already contains image/question information, but no separate pooled visual read. Equal trainable count and exposure do not imply equal function classes or inference cost.

The pool uses its existing private CPU seed24 initialization: A uniform in ±1/sqrt(3608), then slot queries standard normal. Independently initialize the four read matrices with a private CPU generator at the explicit reader seed, in Q,K,V,O order, uniform in ±1/sqrt(fan_in), filling each contiguous matrix in row-major order. The control uses its own private generator at that same explicit seed, down then up, with the same fan-in rule. Constructors default to seed25; the software profile fixes25, and a later separately registered two-seed replication may fix25/26. The pool always remains fresh seed24. No seed is selected from outcomes. All tensors are FP32; both scalar gates are zero. Different-shaped matrices do not claim identical bytes. Preserve the frozen ordinary checkpoint exactly; no new LoRA initialization or training occurs.

Do not also zero W_O or B_up. At step zero, a finite branch output permits a gate gradient; branch-weight gradients are expected to be zero until the gate moves. Keep the branch computation in the autograd graph even when alpha is zero. A parameter-dependent shortcut that returns h_t without computing the branch would strand the gate. Software validation must demonstrate actual native torch.equal logits/identical greedy IDs at initialization under matching eval/no-grad contexts and call shapes, a meaningful gate gradient in a separate grad-enabled check, and live branch gradients after a gate update. A changed requires_grad path can select another native quantized/attention kernel even with identical input values; it is not silently treated as an algebra failure or waived after outcomes. Real-arithmetic identity is not a universal CPU/GPU bitwise guarantee; finite native cast/add, same-shape calls and nonfinite checks are part of that validation.

## Frozen-state training cache

Caching is mathematically valid for this specifically frozen/eval backbone: save the **complete native sequence of inputs to block27**, after blocks0–26, for each exact teacher input; also save original IDs, all native positions/masks, prompt width, targets and frozen postmerger features. Those lower states are independent of either new residual's parameters. Base eval mode disables the fitted LoRA's dropout in both cached extraction and the corresponding uncached reference; it does not reproduce the old LoRA-training trajectory, nor is that claimed.

The reference optimization forward rebuilds the current summary/read or pointwise residual and replays the entire causal final block with all historical assistant writes live. Reuse the actual frozen final block, rotary module, norm and head with gradients enabled through their inputs. Do not wrap this replay in inference_mode or detach K/V at any written assistant position. Retain the original last-L head-call shape and full JSON+EOS CE/scene weights; gold target suffixes are causal teacher inputs, not additional future-answer features at earlier positions. Saving only the first/last query state, a final norm state, a trained-summary value, or detached written-position K/V would change this objective.

A cheaper equivalent is possible because the write mask starts at W−1: cache the **unchanged final-block prefix K/V at positions0 through W−2**, together with frozen lower hidden states for all L positions W−1 through W+L−2. The prefix cannot depend on a future write under the causal mask, so it is constant with respect to both new modules. Recompute all L modified suffix states and their final-block attention jointly on every update, retaining the live suffix K/V graph and access to the constant prefix. Native absolute cache positions, rotary coordinates and original head shape remain mandatory. The installed mask helper queries layer0 (or the first full-attention layer), whereas the final attention writes cache layer27: a cache populated only at27 must not infer mask length through the default layer0 path. Build an explicit absolute-offset mask of shape [1,1,L,W−1+L], allowing key j only when j<=W−1+t for suffix query t and the original padding mask permits it. Seed a fresh cache with only the unchanged prefix at its actual layer27; do not renumber the frozen layer or retain a previous update's suffix. This is a conditional engineering optimization, not another architecture arm: accept it only after full-prefix versus prefix-KV/suffix replay agrees under a prospectively fixed native-logit/loss/gradient audit at zero and nonzero gates. Kernel-shape differences can prevent exact floating-point agreement even when the real-arithmetic computation is identical. Earlier cross-question and learned-memory cached/full-prefix numerical failures are not repaired or waived by this argument; prior software is not a nonzero-gate parity proof for this checkpoint.

Both learned arms receive exactly the same original training rows/order, target exposures and predeclared optimizer/update budget; the untouched checkpoint is an anchor, not the matched extra-exposure control. A later fit protocol must bind the chosen budget before training. Cache extraction, storage and transfer cost are shared experimental work and disclosed separately. Full teacher-state storage can be substantial and needs input-only sizing. Require cached-versus-uncached native logits, loss and new-parameter gradient checks at zero and nonzero gates before release. Finite-shape/kernel differences and backward support through the frozen native quantized final block remain software risks. Natural evaluation uses actual emitted prefixes through the complete native backbone; teacher-state caches cannot stand in for autoregressive inference or its cost.

## Decision and limits

The smallest scientific comparison is these two equally exposed learned residuals against the fixed ordinary anchor. Freeze new-world evaluation families under the original task law before fitting; the already inspected official pilot can only be exploratory. The planned contrast must show better complete relational answers than **both** the pointwise control and the anchor, with paired-world uncertainty, separate task results and retrieval preservation. A format-only, answer-prior-only or generic-adapter improvement does not identify explicit aggregation. Counterfactual worlds should vary relevant relation load separately from distractors while controlling total length and rendered Step/ordinal exposure. Choose their counts and uncertainty margins prospectively, not from a favorable historical stratum.

This block is standard machinery. [Flamingo, sections2.1–2.2](https://arxiv.org/html/2204.14198#S2.SS2), already combines visual resampling with language-query cross-attention and a zero-initialized tanh residual gate. [BLIP-2, section3.1](https://arxiv.org/html/2301.12597v3#S3.SS1), already uses32 learned visual queries. The pointwise comparator follows the established bottleneck-adapter pattern of [Houlsby et al., section2](https://proceedings.mlr.press/v97/houlsby19a/houlsby19a.pdf), with this design's explicitly declared gate and bias-free parameter match. No novel attention, low-rank map, resampler or KV-write principle is claimed.

The empirical hypothesis concerns a complementary aggregation computation while preserving the evidence path. A summary may still be uninformative, the single final block may be unable to use it, the gate may not optimize, or the branch may interfere with retrieval. A negative result does not isolate these causes or prove information loss. If it cannot beat the matched pointwise adapter and anchor under the fixed exposure while preserving retrieval, stop this one configuration; do not rescue it with another placement, width, loss, gate or seed sweep. A positive pilot still requires fresh-world/two-seed replication and a gain within native reasoning mode, at a matched total measured inference allowance. Merely matching accuracy at lower cost is efficiency; adding cost without a controlled relational gain does not meet the user's objective. Independent-question reuse is an optional later study, not a prerequisite for reasoning-token composition. No content-mass claim follows from this normalized-only design.
