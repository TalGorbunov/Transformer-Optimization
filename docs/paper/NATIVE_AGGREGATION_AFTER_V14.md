# Prospective decisions after V14

Written while all four V14 models are evaluating their fixed test sets; no V14 accuracy outputs have been inspected. This is a scientific decision memo, not an experiment release.

V14 measures complete native answers and the fidelity of converting a trained empirical-bank operator into a small mean predictor. Its conversion diagnostics cover training queries and ordinary training positions. Even excellent fidelity there cannot certify native behavior at64frames or at an erroneous generated prefix. A failure on the fresh test therefore does not, by itself, distinguish a bad aggregation principle from a poor inference-time approximation.

If needed, the narrowest additional attribution test is a matched native comparison between the learned mean and the live empirical bank mean. Both conditions should receive the same N actual images,24 known-null reference streams and one global stream. Both compute the same messages and predictor; only the chosen mean changes. Keep the trained coefficientN for centered models and1 for offset models, with no training-length anchor. Recompute at each condition's actual generated prefix. Use all four fixed models and every answer value, selected by a fixed family rule. This is exploratory reuse and adds reference-image cost; it cannot become the deployed method's main result.

The augmented learned condition also needs a descriptive comparison with its saved N+1 outputs. Added batch rows can change native numerical execution. Matching the two augmented conditions controls that difference within the diagnostic, while leaving a limit on attribution to the original deployed trajectory. A bank rescue would support a calibration or compression limitation relative to this finite reference. Failure of both would leave message variance, position shift, and readout limitations unresolved.

A distinct question concerns reasoning composition. V11's software experiment established that writing before the last block gives later numeral CE a gradient to an earlier aggregation residual; the final-norm write had zero gradient along that path. This is a real computational distinction, not efficacy evidence. The present final-norm method can reread images at later tokens and convey evidence through generated text, while its fixed-prefix native cache receives no continuous scene-dependent aggregation write.

If calibration becomes faithful but complete answers remain weak, the existing matched pre-last versus final-norm design is a more direct test of the user's composition objective. Both arms should read the same penultimate features and share calibration, parameter count, data and losses. Historical writes must remain live during training. The present frozen final-state cores cannot simply be moved earlier: that changes their trained input representation or requires an extra replay. New common-read features and training are required, with measured last-block backward cost.

Placement changes both current-token processing and historical memory. A subsequent fixed-checkpoint intervention can retain the current write while removing previous assistant-query writes at every prescribed teacher prefix. First-token outputs should be unchanged; later effects would isolate use of those historical writes at fixed text. This must be distinguished from free-running reasoning efficacy.

Null-variance regularization remains a separate hypothesis about noisy irrelevant evidence. Mean centering alone does not eliminate variation in individual messages, and position-dependent nuisance shifts remain possible. Another fit should follow a clear attribution question, rather than a search over penalties. Neither centering, set aggregation, nor persistent state alone establishes a new attention family or an information-capacity theorem.

## Conditional compression follow-up, before V15 outputs

If the matched live bank materially rescues native answers, the first compression comparison should hold the core and predictor architecture fixed. V14's normalized raw-mean regression distributes error across message coordinates, while inference subtracts the frozen aggregate projection W of that mean. A fixed projected metric can test whether the allocation of approximation error matters:

`L_projected = mean_q ||W(c(q) - mu(q))||^2 / (||W||_F^2 * v_q)`

Here v_q is the existing fixed per-group message-energy denominator. For W=I this reduces to the current raw-mean objective. Keep all972groups, the same96-to96-to96predictor, initialization, carried order and8000updates. The core stays frozen. Compare all training-group projection errors and ordinary nonlinear substitutions before independently scored native answers. This changes optimization geometry, not the predictor function class; a negative result cannot establish insufficient capacity.

Residual or native-distribution distillation would target later stages more directly, but can hide correction error through training-scene saturation or agreement on only short-context teacher prefixes. A standard width increase is a separate capacity-plus-optimization intervention, justified only after a fixed objective still leaves consequential stationary-target error. Cached reference targets versus live native reference states remain a distinct limit even if a larger predictor fits the cache perfectly. No lookup tables, question/prefix identifiers or numeric answer rules are proposed.

This is an unreleased decision branch. V15 accuracy and decomposition must determine whether compressing the mean remains the relevant next step. No new fitting or architecture expansion is authorized by this memo.
