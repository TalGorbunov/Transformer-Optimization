Both the product and additive models solve all108 original training scenes with ordinary native greedy generation of the complete name and canonical EOS. Both solve all18 complete six-context families. The independent report is [report443592](../../outputs/native_aggregation_vlm/identity_join_factor_native_v2/report_443592/REPORT.md).

Each model uses its fixed6000-step checkpoint. Each image has its own parallel native stream, alongside an image-free global question stream. A learned96-dimensional per-image message is summed and mapped back to the global residual before the native final normalization/head. At each output token, the same emitted prefix is available to every stream. The product arm multiplies two local nonlinear projections; the equally sized additive arm averages them. Both use the same fixed training-derived centering and scalar scale. No symbolic person/room labels enter inference.

Native integration does not change weights, training statistics, prompts or target IDs. The native residual is cast to FP16 before addition to the final global row. The write is outside persistent KV state; any benefit across output tokens is mediated by the emitted prefix. Each output token executes one batched model call across N+1 streams, whose computation must be counted explicitly.
