# Pending optimization decision after the orientation-complete code control

This note proposes a diagnostic interpretation, not an experiment release. The current visual fits fail and their native/fresh evaluations remain held. The exact-local-code216 experiment must be reviewed and completed first.

The mapped training order has54 base pairs per cycle and alternates each base pair's orientation at its next visit. Consequently almost all current16-scene minibatches share one orientation. Global coverage is balanced, but individual update gradients can favor opposing affine shortcuts in successive cycles. Nonzero late gradient norms near a trio-only loss are consistent with this possibility, without establishing it.

For ideal signed room-difference coordinates d, an affine classifier has logits b+Wd. Pairing the same target at d and-d gives a derivative with respect toW proportional to[softmax(b+Wd)-softmax(b-Wd)]d^T. AtW=0 this vanishes, and the direct target term cancels. Even features can still carry the join signal. This identity concerns the ideal affine submodel; native features, the full nonlinear network and Adam states need not obey an exact cancellation.

If the constructive witness passes but the learned code control fails, one general optimization comparison is to place both orientations of each base pair in the same update: four base pairs times two lengths times two orientations, still16 scenes. Keep the architecture, unfitted initialization, optimizer, learning rates, CE reduction,6,000 updates and entire48,000-presentation multiset unchanged. For each consecutive complete two-cycle group, emit bundles in its original-orientation cycle order, pairing each entry with its flipped counterpart by base ID. Flatten all444 lists, group four bundles per update, and retain the final48 original-orientation entries as six final batches. Four base-pair visits need not have distinct IDs at a cycle boundary; this is allowed and will be counted descriptively. The resulting5,994 balanced updates plus six tail updates preserve the47,952 paired entries and48 unmatched entries exactly. Derive and audit the permutation before fitting; do not assert an unchanged per-update target-row count or unchanged order signature. This changes minibatch covariance and the relation between examples and learning rate; it is not an added consistency objective, inference operation or proof of convergence.

If the learned code control passes, the same visual failure remains compatible with difficult feature learning or conditioning. A balanced-minibatch control of the fixed visual product/additive pair could still test this ordering confound, but code success alone would not establish it. Neither outcome justifies a symmetry-specific activation, new semantic labels in deployment, an unlimited training extension, or a bandwidth claim. Any later fitted visual model still needs whole-answer native validation, fresh groups and length extrapolation, then matched adaptation and useful reasoning composition.
