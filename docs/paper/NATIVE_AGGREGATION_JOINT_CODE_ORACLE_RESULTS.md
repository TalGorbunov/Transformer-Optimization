The readout consumed `0.5 * SUM(codes)` and the cached global query through Wagg, SiLU and U, so it still had to learn the join.

The earlier [answer-code control](NATIVE_AGGREGATION_READOUT_DIAGNOSTIC_RESULTS.md) achieved 108/108 and 18/18 by supplying the correct answer's code **after SiLU**, fitting only U. It bypassed both the join and the nonlinear readout tested here, and used first-token supervision with the original sequence-length weights. Its success therefore did not establish that this local-code/readout combination could learn the join under the present full-sequence recipe. This new failure also does not show that the explicit joint codes lack the required information: they preserve the relevant person–room associations. No information ceiling, impossibility or general architectural conclusion follows from one fixed-budget fit.
