# Conditional baseline: a frozen native semantic gate before vector aggregation

If the canonical-image V17 audit shows that the frozen model's original local N1 prompt reliably distinguishes zero from one, the next baseline should test whether that existing distinction can protect vector aggregation from irrelevant images. This is a controlled test of a semantic gate, not the proposed final research contribution. V17 does not release training, establish aggregation performance, or validate the gate's future execution route. [V17 audit source](../../scripts/audit_native_vision_v17_local_readout.py).

The gate rule is fixed prospectively. For image i, let h_i,0 be the local stream's native hidden state immediately before the final norm, at the last token of the original prompt with no generated answer prefix. The prompt remains `build_count_prompt(question, 1)`, with the original image and question. Apply the actual frozen FP16 native norm and language head, obtaining logits ell_i over the complete native vocabulary. Compute probabilities with a full-vocabulary normalization:

`p_i(k) = exp(ell_i[k] - logsumexp_v ell_i[v])`

`g_i = max(0, p_i(1) - p_i(0))`.

Use the tokenizer's verified single-token IDs for literal ASCII `0` and `1`. Promote the native logits to FP64 for the normalization and difference, then detach and store g_i in FP32. Do not renormalize over only those two tokens, threshold a conditional binary prediction, tune a temperature, or rescale the gate. Probability mass assigned to other vocabulary entries must reduce the gate's magnitude. A tie closes the gate. V17 must therefore be assessed using its full-vocabulary mass and positive/negative errors, including false negatives across the registered canonical Step and nuisance slices; strong conditional binary accuracy alone is insufficient. No alternative gate may be chosen from the same diagnostic outcomes.

At answer or reasoning position t, the trainable branch uses the current local state h_i,t and global query state. A concrete rank-96 form is:

`q_t = Wq RMS(h_global,t)`

`v_i,t = tanh(Wlocal RMS(h_i,t) + q_t + b_local)`

`m_i,t = g_i * v_i,t`

`z_t = sum_i m_i,t`

`delta_t = U SiLU(Wagg z_t + q_t + b_agg)`.

RMS and branch arithmetic remain FP32, with the existing fixed RMS epsilon. All 96 payload coordinates pass through tanh and the same scalar gate. There is no reserved count coordinate, direct scalar tally, explicit sum of binary predictions, reference bank, subtraction of an estimated mean, teacher replica, or separate mean predictor. The native head is part of the same frozen backbone. The learned readout still has to turn a sum of bounded vectors into the complete native answer. Its FP32 residual is cast to the native hidden dtype and added only to the current global query before the native final norm. U starts at exactly zero.

The matched control uses `g_i=1` for every image. It must nevertheless execute the same native probe, full-vocabulary normalization, gate caching and dense payload computation. Both arms have the same parameter shapes and count: 1,041,600 trainable parameters at hidden size 3,584 and rank 96. Gate computation adds no trainable parameters. Use matched initializations, presentation orders, seeds, canonical training images, optimizer schedule and losses. The natural starting objective is the existing native sequence CE plus paired residual consistency, with coefficient one in both arms and no null-prediction loss or distillation phase. Gradient values need not match between arms. An augmentation factor, bank arm or nuisance-specific correction should not be added to this comparison. Exact budgets, future seeds, final-checkpoint rule and fresh evaluation set require a separate preregistration and release.

The current runtime already provides most of the causal layout. [`prepare_scene`](../../scripts/native_vision_v7_runtime.py) constructs N independently prompted one-image local rows followed by one text-only global row, preserving the original pixels before the registered resize. Its `audit_layout` checks packing and native mRoPE positions. [`ParallelLocalNative._before_norm`](../../gnnformer/parallel_local_native.py) reads the last local and global query states before final normalization, computes a branch residual, and writes a new tensor with only the global query changed. The new controller should retain this boundary and out-of-place write.

On the original prefill, the controller would gather the untouched final-query slice as `[N+1,1,3584]`. It would call the bound native `norm.forward` and `lm_head.forward` directly, then use only the N local rows to form the gates. Direct `forward` calls bypass module pre-hooks, preventing recursive fusion; the global probe row is discarded. The native forward subsequently resumes its ordinary norm and head after the global residual is inserted. This keeps the probe's head batch shape explicit. Existing captured-state replays use the same direct-call pattern, but they do not validate this new in-hook execution. [Existing replay pattern](../../scripts/profile_native_vision_v13_null.py).

Cache the original g_i and its full provenance once per trajectory. At later cached positions, recompute the payload from the current states but reuse these gates exactly. A full-prefix diagnostic must receive the same bound original gates; it must not recompute them from the last token, an appended gold numeral, or the model's evolving answer. Cached and full-prefix routes should therefore agree on the gate artifact even when native hidden-state arithmetic differs descriptively. A fresh scene/controller resets the cache; a standalone full-prefix call without an explicitly bound origin must fail. Training on cached causal-prefix features similarly broadcasts each image's empty-prefix gate to all of that image's target positions.

The existing `GlobalBroadcastLogitsProcessor` can continue to broadcast the global raw argmax to every row. Gate probabilities do not mask, bias or replace the global vocabulary. The local probes do not generate local tokens or call `generate` separately. Because the write remains after every decoder block, all decoder KV entries stay native for a fixed executed token history. Generated histories can still change through the global output; that effect must not be confused with modifying KV tensors. Preserve the runtime's exception-safe hook cleanup and rope-state restoration, exact prompt/prefix ledgers, per-row positions, raw global logits and native EOS policy.

For a trajectory with T generated tokens, the added inference work is exactly one extra native norm call and one extra full-vocabulary native head call on N+1 query rows, plus one full-vocabulary probability normalization. The ordinary native model still makes T forwards, T ordinary norm/head evaluations and one vision prefill. Total norm/head evaluations are T+1 of each, with the extra norm operating on one query per row rather than the whole prompt. There are no extra VLM, decoder-block or vision calls and no reference-image rows. Both arms pay this work, including all-open. Instrument the direct calls explicitly because normal module-hook counters will not see them. The head cost and vocabulary tensor allocation are real; “one forward pass” must not be presented as free computation.

New software tests are necessary before treating cached V17 readouts as deployed gates. They should check zero-U native identity; the direct probe against the actual same-forward native local logits at the same head shape; local and earlier-global state preservation; every layer's fixed-prefix KV identity; original gate identity through cached and full-prefix execution; and absence of backbone gradients. The all-open arm must execute the same probe work. Test full-vocabulary mass explicitly, including a case where `p(1)>p(0)` but both are tiny, and confirm that a closed gate zeros all 96 message coordinates. Retain all raw numerical discrepancies and failures. V17's cached/head-only batches and prior TV/top1 checks do not establish kernel equivalence for this new N+1 in-hook path. Any comparison tolerance and fixed call inventory must be registered before that profile, with no silent replacement of gate values to make a check pass.

This baseline has clear limits. A false negative with g_i=0 removes that image's payload at every subsequent position; later reasoning tokens cannot reopen it. Weak positive gates also attenuate useful information. Small false-positive gates can still accumulate with N, and bounded payloads do not make true positive messages identical or guarantee a correct decoder. An empty aggregate can still produce a query-dependent readout; it does not hard-code the answer zero. The gate is tied to the original counting question and the pretrained meanings of `0` and `1`, so it is not a general mechanism for changing subquestions during reasoning. Current payloads can evolve over generated tokens, but compositional reasoning benefits remain an empirical question.

A successful matched comparison would show that this fixed, native semantic prior helps the learned vector aggregation and readout under the registered conditions. It would separate semantic selection from learning all of relevance and aggregation together. It would not establish a new attention operator, a universal aggregation law, or the final research contribution. No images, gates, model parameters, Slurm jobs or training releases are created by this proposal.
