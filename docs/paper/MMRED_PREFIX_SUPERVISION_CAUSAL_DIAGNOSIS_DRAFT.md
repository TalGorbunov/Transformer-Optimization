# Draft: does the supervised state contain and control the answer?

This is a prospective follow-up design, not an experiment release. It does not
change the six running fits or the frozen fresh1400 comparison. The40 channels
are an engineered diagnostic representation; successful linear decoding alone
does not establish causal use or structural capacity.

Select eight complete diagnostic families, two per N16/N32 by partner/room
cell, from the existing fixed metadata. Selection uses source order and oracle
metadata only, with no prediction filtering. Prefer unchanged-answer controls
whose task-relevant totals differ; record any quota shortfall rather than
searching different seeds. Eight families contain32 worlds and48 existing
questions. Use all seven fixed checkpoints and both directions of each paired
transformation.

During unmodified generation, passively record the image-end states before
decoder block27. Apply the existing frozen projection/affine constants offline;
never clip or recalibrate. Record local indicator error, inclusive cumulative
count error, increment residual S_hat[t]-S_hat[t-1]-F[t], and person-room
conservation sum_room S_hat[t,person,room]-t. Separate positions through16 and
beyond16. Compare amount errors with ordering errors, and inspect growth with
prefix length. Poor decoding of unsupervised states only shows failure of this
particular engineered readout, not absence of information elsewhere.

For causal use, capture actual paired donor activations within each checkpoint.
At every recipient image-end position after the shared cut, transplant only
the40 projected coordinates. For column vectors, use

    h_new = h + P.T @ inverse(P @ P.T) @ (P @ h_donor - P @ h)

Apply this during prefill only, then continue ordinary native cached generation.
Keep the recipient's orthogonal complement and all other positions. Use the
stored FP32 projection, independently verify the small Gram solve, and report
actual post-cast projected changes and perturbation norms. A donor's activation
is natural, but its combination with recipient activations may still be off
distribution; the intervention does not automatically become valid by using a
real donor.

Compare unmodified generation, the projected-coordinate donor transplant, and
a fixed rank40 complementary-subspace perturbation matched in per-position
norm. Freeze the complementary basis, sign/direction rule and matching precision
before execution. Add identity-hook checks on four fixed questions per model.
On one changed pair per N/task cell, also transplant the full hidden rows as a
positive test of whether this late route can influence the answer; full-row
transplants are not magnitude-matched controls. Same-answer world pairs and
invariant atomic questions measure nonspecific disruption.

Report donor-oracle answer agreement, agreement with the donor model output,
both-members-correct, unnecessary changes for unchanged-answer pairs, and
atomic preservation separately. Do not filter on baseline correctness. Group
descriptive uncertainty by complete family. The small panel diagnoses routes;
it does not support a newly powered superiority claim.

The existing960 diagnostic questions contain no absolute-count diagnostic.
A separately registered extension can add eight original-template
steps_in_room questions to the unchanged room-control pairs, choosing an
oracle-identified room whose count changes while the MOST room remains fixed.
This distinguishes a winner-label representation from usable amounts. Such
new questions must be recorded explicitly; they are not already part of the
frozen960.

The base panel has336 unmodified trajectories,336 projected transplants,
336 complementary perturbations,28 identity checks and56 full-row transplants:
1092 total across seven models, at most54600 native decoder/head calls. Shared
vision encodes32 worlds and768 frames once. The eight additional count questions
would add168 trajectories, giving1260 and63000 calls. These are inventory bounds,
not measured runtime forecasts. A separate software/cost check, source release
and resource allocation are required before execution.

Interpretation is conditional. Good local facts with poor cumulative growth
motivate an accumulation/calibration investigation. Accurate totals with a
specific donor-answer transfer support use of this taught state. Accurate totals
without transfer leave readout, redundancy and intervention validity unresolved.
Similar disruption from target and complementary perturbations supports no
semantic causal claim. Failure at this boundary never establishes architectural
incapacity. This diagnosis is informative even if the primary fresh gain is null.
