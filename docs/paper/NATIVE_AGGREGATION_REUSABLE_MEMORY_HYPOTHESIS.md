# One hypothesis for reusable visual aggregation

Prospective research design only: no implementation, data generation, fitting or inference is released. The ordinary joint-image LoRA competence control is pending; no baseline success is assumed. The216-context aggregation-architecture search remains closed. This note follows the [objective alignment](NATIVE_AGGREGATION_OBJECTIVE_ALIGNMENT.md), [relevant-load distinction](NATIVE_AGGREGATION_RELEVANT_LOAD_DESIGN_NOTE.md) and [conditional LoRA confirmation](NATIVE_AGGREGATION_JOINT_LORA_CONFIRMATION_DESIGN.md).

**Hypothesis:** a fixed-size visual memory constructed before any question can improve complete cross-image relational answers as relevant evidence increases, under the same measured total inference budget as a competent adapted ordinary joint-image model, without sacrificing independently requested facts or relations. The same result must subsequently hold with a plain decoder and a reasoning decoder. Equal accuracy at lower cost would establish efficiency, but would not establish the hypothesized aggregation-accuracy gain.

Use one fixed32-token learned-query resampler over frozen, question-independent visual encoder features of the complete collection, retaining native spatial/image-order information. Project those tokens into a normal decoder prefix and build its ordinary KV once. Every question starts from that identical visual-prefix state; question, answer and reasoning KV are reset between independent questions. The resampler receives no question, target, privileged scene graph, answer-dependent selection or generated prefix. It is trained through the separately posed questions' answer losses, not given their answers as memory inputs. During answering, one ordinary decoder forward runs per generated token, with no N+1 local decoders, re-encoding, retrieval call or second VLM pass. Initial vision encoding, compression and prefix construction remain real, charged work. Fix this architecture and memory budget; no token-count, layer, activation or normalization sweep follows a failure.

This topology differs from the existing question/prefix-dependent local decoder bank. It also differs from a final-norm residual that cannot directly enter later KV. However, this repository already has software-verified pre-last-block KV writes for Qwen and Cosmos, without fitted benefit; putting evidence inside KV is not itself a new result.

The smallest informative pilot uses one plain backbone first and newly frozen, world-disjoint collections. One concrete scene law contains two disjoint requested-room pairs, each with K candidate identities appearing twice: one unique cross-room person and balanced same-room alternatives. Two independently varied joins then require4K relevant frames in total. Set K to3 or7 and cross it with0 or8 irrelevant frames. Ask four independent questions per world: two atomic Step/person lookups and the two distinct cross-image joins. Change either join's answer while preserving person/room marginals and the other join; complete counterfactual families must accompany per-question scores. All identities, rooms and query programs occur in training. This first assay compares held-out worlds at both supported loads; it is not automatically out-of-load extrapolation.

Step/ordinal sensitivity is an already observed nuisance. Training must expose the full rendered Step range and positions used in evaluation, with balanced atomic-query indices and no novel visual classes at higher K. Include a fixed matched-total-length control, for example N36 with `(K=3,D=24)` versus `(K=7,D=8)`, alongside the factorial cells. This distinguishes changed relevant content from total context and ordinal exposure. These are data controls, not additional architecture arms. Freeze sampling, exclusions, sample counts and answer-changing families before either model is fitted; neither old failed fresh data nor91726342 outcomes may tune them.

The comparator is the same ordinary joint-image backbone, resolution and ordered evidence, with the same language-adapter scope, initialization, training worlds, question exposures and optimizer-update budget. It receives all original visual tokens and may build and reuse its image-prefix KV once across the four questions. Reset its question/answer KV identically. Account for the resampler's additional trainable parameters and training work; this is not equal-parameter training. A common inference allowance must be large enough to run the complete ordinary joint baseline, not force it to omit images or truncate answers. Freeze each model's decoding/token allowance after input-only profiling, before outcomes; do not use outcome-selected extra sampling, traces or retries. Measure from collection encoding through all four answers, including cache construction/copying, every generated reasoning token, peak memory and persistent KV bytes. Report cold and reused-prefix costs separately. Budget equality is an audited compute condition, not a synonym for equal token counts.

A concrete effect bar for the later protocol is at least a five-percentage-point gain in worlds with all four complete natural answers correct at K7, at no greater total measured inference allowance, with no more than a two-point loss on either atomic/independent question or the K3 condition. Predeclare world-clustered uncertainty and sample sizes sufficient to distinguish those margins; report every load/distractor cell and complete-family outcome. The ordinary baseline must first demonstrate elementary and low-load competence on this new task. Failure there leaves the assay unresolved. A plain-model success is only the first stage: meeting the user's stated objective requires the same relational benefit with a native reasoning model, a fixed reasoning allowance and final-answer scoring, without forcing intermediate answers. This tests two-fact visual composition, not unrestricted reasoning ability.

Closest primary precedents delimit the claim:

- [BLIP-2](https://arxiv.org/html/2301.12597v3), sections3.1–3.3, already uses32 learned queries to compress frozen visual features and project them into a language-model visual prefix.
- [Flamingo](https://arxiv.org/html/2204.14198), sections2.1–2.3, already combines fixed-size visual resampling with language-model access to visual representations. Its original per-image cross-attention mask is not this proposed whole-collection prefix.
- [Matryoshka Query Transformer](https://arxiv.org/html/2405.19315), section2, already studies learned visual-token compression and accuracy/compute tradeoffs. A smaller prefix alone is not a new contribution.
- [HiLS](https://arxiv.org/html/2607.02980), section3, learns chunk summaries for query-dependent routing and attention-mass allocation while retaining selected token-level KV. It is a relevant efficient-access precedent, not evidence that one fixed memory can replace all original visual evidence across independent questions.

The possible contribution is a demonstrated relevant-relation accuracy gain under controlled reuse and measured budgets, plus its failure boundary across plain/reasoning models—not a new attention or compression primitive. If the fixed memory loses independent answers, gains only on distractors, exceeds the budget, or fails to improve higher-load complete answers when the comparator is competent, this hypothesis fails and the configuration stops. An efficiency-only result is labeled as such. No architecture rescue, larger memory, extra fitting or fresh-set reuse is authorized by this note.


## Pre-implementation refinement, 2026-09-12

The first benchmark pilot should use four original MMReD tasks: `spend_together` and `where_spend` as the primary multi-counter aggregation tasks, `steps_in_room` as a tally control, and `char_at_frame` as a retrieval control. Recover and audit the pinned original data before freezing sample lists. The original benchmark has five persistent people and six rooms; one person moves each frame. Its longer sequences increase integration length, not the number of distinct identities. The K7/nine-person construction above is a separately derived diagnostic, not the original benchmark. Preserve the original question and evaluation format as the primary endpoint. Additional questions over the same world form a separately reported reuse panel.

A clearer memory target than a normalized resampler alone is to retain its attention mass. For fixed learned slots and item-local key/value maps, define `S_k = sum_i exp(score_ki) value_i` and `Z_k = sum_i exp(score_ki)`. Present `(S_k/Z_k, log Z_k)` to the learned visual-prefix projection. The normalized-only control receives the same value summaries and a zero mass feature, with the same parameter shapes. This is a prospective mechanism comparison; neither variant has been trained or released. Slot widths, positional encoding, optimizer and data budget must be fixed together before fitting.

The accumulator is an ordinary stable online-softmax state `(maximum, scaled S, scaled Z)`. Chunks merge with max/exponential rescaling, with globally consistent coordinates and fixed slot queries. These are established algebraic operations: linear attention already retains separate numerator and normalizer states ([Katharopoulos et al., 2020, section3.4](https://arxiv.org/html/2006.16236v3)). The failure of normalized aggregation to preserve multiset cardinality also predates this project ([Zhang and Xie, 2020](https://www.ijcai.org/proceedings/2020/194)). No new attention primitive or general injectivity theorem is claimed.

If identical enriched items are replicated c times, the normalized summary stays fixed while log mass increases by log(c). This is an explicit multiplicity signal, not an object counter: weighted patch mass need not count people or events, and different bindings can still collide in finite summaries. Giving replicated images new positions also invalidates literal duplicate invariance of the enriched inputs. All such limitations must remain visible. Native decoder training may ignore the mass feature; the matched normalized-only control tests whether it helps.

The small draft `gnnformer/attention_moments.py` implements only this known numerical accumulator. It neither loads a model nor creates a memory prefix, performs visual reasoning or establishes improved aggregation. Its CPU fixtures check reference outputs, partition/merge gradients, multiplicity, empty identities and numerical stability. Separately, the shared native image-prefix runtime must establish faithful ordinary-model cache reuse before any compressed-memory accuracy comparison.
