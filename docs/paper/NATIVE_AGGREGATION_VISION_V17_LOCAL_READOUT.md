# V17: prospective native local-readout audit

Source preparation only. This draft is not an execution release; the parent records the final protocol before any job. No V16 outcomes were read when choosing this audit. No fit, feature extraction, VLM/vision forward, answer generation, or model selection occurs.

The question is whether the frozen native local state already supports reliable isolated 0/1 judgments, including the long contexts on which the V14 aggregate answers failed. A positive result motivates a supervised relevance/value interface; it does not prove that a new gate will learn, that vector values are nuisance-free, or that the native aggregate decoder works. A negative result defeats the premise that these current states have a robust native local readout. It does not establish information absence or rule out another trained readout.
