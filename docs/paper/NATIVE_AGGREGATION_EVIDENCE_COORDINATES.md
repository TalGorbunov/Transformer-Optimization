# Local competence is not yet additive evidence

Prospective design note,2026-09-10. Written while V6 main array441650 is training, before fresh test outputs. This is a candidate explanation and next-step design, not a V6 finding or an authorized V7 protocol. The fixed V6 head-subspace diagnostic is separately registered in PREREG_AGG.md.

The central question is whether the model accumulates a representation of each item's contribution, rather than merely a representation from which its local class can be decoded. V6's auxiliary loss teaches local classification. Its native answer pathway still sums the entire96-dimensional message. These are different requirements.

Let local logits be a_i=A m_i+b and probabilities p_i=softmax(a_i). For a fixed three-way classifier, C=I−11ᵀ/3 removes the common logit shift. The projector P=(CA)⁺(CA) has rank at most two and satisfies softmax(APm_i+b)=softmax(Am_i+b) in real arithmetic, retaining the same bias. The complement Q=I−P is invisible to that fixed classifier but may affect the native write UΣm_i. Count CE can train useful information in Q; A rotates during training. This argument neither identifies Q as nuisance nor says only two dimensions were trained.

The registered CPU analysis therefore measures both parts without changing predictions. Orthogonality in message coordinates does not imply orthogonality after U: the native metric is UᵀU and includes cross terms. A large Q contribution alone is not evidence of harm. The projector also depends on the chosen latent-coordinate metric. Any causal projection test needs fixed examples, all checkpoints, and attenuation/random-projection controls; it remains unregistered here.

Even retaining only classifier-visible information does not make a valid count representation. Consider logits [0,a,−20]. A sequence containing a=15 and a=−5 has one confidently positive and one confidently negative item. A second sequence containing a=5 twice has two confidently positive items. Both have identical summed logit contrasts (10,−40). Local classifications are correct in both sequences, but a decoder receiving only those summed contrasts cannot distinguish their counts. This is an illustrative counterexample, not an empirical observation from V6.

A smaller next experiment, conditional on strong V6 local transfer and weak aggregate answers, would freeze each dev-selected V6 reader and classifier and compare what is summed:

- Probability coordinates: $f_i=(p_{i,1},p_{i,\mathrm{other}})$.
- Log-odds coordinates: $f_i=(a_{i,1}-a_{i,0},a_{i,\mathrm{other}}-a_{i,0})$.
- In both cases, inject δ=DΣf_i through the native branch, with shared bias-free D of shape3584×2 and zero initialization.

The probability notation above uses the second index as a class label: p_i,1 means the probability of class1 for image i. Both representations carry the same single-item information in the simplex interior. Their sums preserve different information about the collection. Each arm uses7,168 readout weights and at most rank-two native writes. The existing query already conditions m_i; an extra query-dependent mapping is unnecessary. Matching upper-four LoRA adaptation would give728,064 trainable readout/LoRA parameters while the local reader/classifier stay frozen. This would test aggregation coordinates without letting count CE change local perception. Initial scale, LoRA initialization, training allocation and fresh-data rules must be fixed before any such run; they are deliberately unresolved here.

The probability code is a minimal parameterization of p_i−e_0. A perfectly recognized noncontributing item p_i=e_0 writes exactly zero. Holding the query and other item features fixed, inserting any number of such items leaves the branch aggregate unchanged. This guarantee is conditional: native queries and visible Step labels can change with context length, and the ordinary transformer still sees every image.

Approximate predictions are less forgiving. If positives have p_i,1≥1−ε+ and negatives p_i,1≤ε−, then |Σp_i,1−K|≤Kε+ +(N−K)ε−. False-positive probability mass can therefore accumulate despite excellent classification accuracy. The other-class coordinate may accumulate too. A correct extensive scalar also does not guarantee that the native language model decodes a numeral: RMS normalization can compress amplitude differences, while residual paths prevent a blanket information-loss claim.

An objective-only alternative is to penalize the actual teacher-negative native write, averaging p_teacher(0)||U m_i||² over training images and native dimensions, alongside unchanged CE and KD. Penalizing only message norm permits a compensating rescaling of U. However, the native-write penalty still admits collapse to a branch the backbone ignores, has physical scale and coefficient choices, and assumes a meaningful noncontributing local outcome. It needs controls before being preferred to the more explicit bottleneck.

The ingredients have close precedents. [Concept Bottleneck Models](https://proceedings.mlr.press/v119/koh20a.html) require the downstream prediction to use supervised intermediate concepts. [Deep Sets](https://arxiv.org/abs/1703.06114) supplies learned elementwise transformations followed by permutation-invariant aggregation. Combining these inside a vision-language residual branch is not a new attention family. Any contribution must come from a clear failure diagnosis and measured native extrapolation gains under appropriate controls.

The current0/1/other teacher is a counting instantiation. It does not establish a task-general semantic vocabulary or correct behavior at arbitrary reasoning tokens. If this direction works on native MMReD counts, a broader claim still requires other aggregation operations and a matched method/control × direct/reasoning evaluation. If local transfer fails, stronger pretrained per-image query computation becomes the better-motivated intervention instead.
